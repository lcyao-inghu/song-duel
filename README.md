# 心選 SONG DUEL

網站交付檔案為 `index.html`。HTML、CSS、JavaScript 全部內嵌，不需建置、後端或秘密金鑰。可直接開啟檔案體驗，真實搜尋需網路。

## 資料與玩法

- iTunes 台灣商店：歌手搜尋 `search?entity=musicArtist`，歌曲取得 `lookup?id=歌手ID&entity=song&limit=200`。
- 使用 Apple 官方文件提供的 JSONP 跨來源呼叫。從 `https://itunes.apple.com` 取得歌曲資料；對戰卡片顯示 API 回傳的專輯封面與專輯名稱，封面僅接受 HTTPS 的 `mzstatic.com` 來源，不使用試聽。
- 封面旁使用 Apple 官方無黑底的 iTunes Store 文字標示（solid black lockup），替代黑底徽章，封面與標示皆連向該首歌曲的商店頁面（`app=itunes`）。標示以官方原始 SVG 內嵌，保留比例、至少 25px 高度與四周留白，不修改圖樣。封面以原圖完整比例顯示；缺圖或載入失敗時提供明確佔位，不影響選歌或返回上一題。示範歌曲不冒用真實封面。結果下載圖仍僅含文字與連線。
- 核對 artistId，無論版本設定，皆排除名稱或專輯名稱標示 Instrument／Instrumental、Karaoke、伴奏、純音樂等歌曲。預設只收錄標準版；勾選「題庫包含標準版以外的其他版本」後，可收錄 Live、日文版、Remix、重製等版本。同一版本仍去重，不同版本可分別參賽。切換設定使用當次原始資料重新篩選，不重送 API 請求，可用數量及模式隨之更新。最多請求 200 筆，來源未標示的純音樂與版本無法單靠文字資料辨識。
- 搜尋延遲 600ms，處理中文輸入法，忽略過期搜尋及歌手回應。相同搜尋與成功歌曲結果在當次頁面中快取。
- 選定歌手後可複選限定專輯，預設不限；依專輯識別碼篩選原始資料後才去重，避免歌曲在其他專輯的版本遮蔽所選專輯。每張專輯顯示目前版本設定下的可用首數，切換不重送網路請求，換歌及重新抽選僅使用所選專輯。
- 可選 2～16 首，保留 8／16 首快捷鍵；不足 8 首時可使用全部現有歌曲。0～1 首無法二選一，提示調整專輯與版本設定。非 2 的次方首數會隨機安排首輪輪空，輪空直接晉級、不要求作答，n 首實際作答 n−1 場。結果圖與紀錄明確標示輪空，返回上一題只回到實際作答的場次。
- 「今天的參賽名單」每張卡片顯示專輯封面縮圖、歌曲、歌手與專輯名稱，縮圖旁附對應商店連結。換歌與重新抽選時同步更新；缺少資料時顯示封面佔位與「專輯：來源未提供」。
- 每題提供「上一步」回到上一場重新選擇，支援跨輪次及連續返回；還原原始配對與晉級狀態，撤銷的選擇不會留在冠軍紀錄或結果圖。第一題及選擇切換中的按鈕停用。重新遊玩及重設會清除返回紀錄。
- 同題兩張歌曲卡片在電腦與手機皆保持等高、等寬，長歌名完整換行。
- 對戰卡片提供來源回傳的 Apple Music 歌曲連結，另開分頁，不影響晉級選擇；實際播放由 Apple Music 頁面提供。示範歌曲及無歌曲連結時會說明原因。
- 結果頁自動產生單張淘汰賽對戰圖預覽，不自動下載。確認後，點獨立的「下載 PNG 圖片」連結才會下載，也可放大檢視。圖片最上方顯示最終冠軍，下方依參考圖樣式，將每場兩首歌放在同一張卡片，標示使用者選擇的晉級歌曲，並連到下一輪；橘色連線為冠軍之路。包含歌曲、歌手、版本設定與比賽數量，長歌名自動換行。全程在瀏覽器內產生，不需圖片服務，沒有傳送比賽紀錄至外部網站，手機可長按圖片儲存。
- 最近歌手最多 5 位；儲存受限不影響比賽。示範模式含 20 首標準版、3 首其他版本與 1 首永遠排除的純樂器版，均為明確標示的虛構歌曲。

## GitHub Pages

指定目的地：`lcyao-inghu/song-duel`。

1. 在該 GitHub 帳號建立公開儲存庫 `song-duel`。
2. 將 `index.html` 上傳至 `main` 分支根目錄。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 部署完成後，網址應為 `https://lcyao-inghu.github.io/song-duel/`；須以 GitHub 實際回報為準。
5. 在該網址測試歌手搜尋、選擇、歌曲數量與完整比賽。未部署前，不視為 GitHub Pages 驗收通過。

## 驗證

`verify.cjs` 是開發用瀏覽器測試，需 Playwright 與 Microsoft Edge。它使用此工作環境的 Playwright 安裝路徑，換電腦時請調整 require 路徑；網站本身沒有套件依賴。

已在本機 Edge 使用真實網路完成周杰倫查詢（當次整理後 189 首）、Ed Sheeran 搜尋及歌手切換。完整測試 8 首 7 場、16 首 15 場、冠軍紀錄、重玩、換歌、模式門檻、歌曲去重、快速連點、離開提醒與手機版面。測試截圖位於 `outputs/`。

補充測試亦已通過：模擬連線失敗與重試提示、查無歌手、歌曲不足、搜尋及歌手過期回應、本機儲存不可用，以及選擇歌曲後立即重置並重開比賽的計時器競態。測試過程沒有頁面 JavaScript 錯誤。

GitHub Pages 發布目標為 `lcyao-inghu/song-duel`。來源部署使用儲存庫預設分支的根目錄，網站交付檔案為 `index.html`。API 結果與數量會隨服務及地區變動。
